Getting Started ​

This guide will help you start using Mantra in 5 minutes.

Download and Install ​

Download the version for your operating system from Mantra website:

  • macOS: Supports both Intel and Apple Silicon
  • Windows: Supports Windows 10 and above
  • Linux: Supports major distributions

Import Your First Project ​

  1. Open Mantra and click the Import button at the top
  2. Select your AI tool (Claude Code / Gemini CLI / Cursor)
  3. Mantra will automatically scan and list importable projects
  4. Select a project and click Import

Note

The first import may take 30 seconds to a few minutes, depending on project size.

Start Time Traveling ​

After import completes:

  1. Left panel shows the complete conversation history
  2. Right panel shows the code state
  3. Click any message and the code on the right automatically changes to that point in time!

Congratulations! You've successfully experienced Mantra's time travel feature.
